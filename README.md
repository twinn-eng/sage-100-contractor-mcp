# Sage 100 Contractor MCP Server

Connect Sage 100 Contractor to AI assistants and automation tools using the Model Context Protocol (MCP).

**Powered by [Twinn Engineering](https://twinn.engineering)**

Twinn Engineering provides integrations for Sage 100 Contractor, enabling developers and businesses to connect construction accounting data with modern applications and AI workflows.

## Overview

The Twinn MCP Server provides a standardized interface for AI agents to interact with Sage 100 Contractor through Twinn's hosted integration platform.

### Use Cases

- **Job Cost Analysis:** Explore construction job expenses and budgets.
- **Inventory Management:** Analyze inventory, materials, and job allocations.
- **Accounting Automation:** Build workflows around financial and accounting data.
- **Reporting:** Generate operational insights using Sage 100 Contractor data.
- **AI Integrations:** Connect supported AI assistants to construction accounting workflows.

*Available capabilities depend on the tools and permissions enabled for your account.*
