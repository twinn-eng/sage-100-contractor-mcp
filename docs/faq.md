# FAQ

### Is this the real Sage 100 Contractor data for my company?

No. The demo server is connected to Ridgeline Mechanical & Plumbing, a sample company. To connect your own Sage 100 Contractor data, contact [Twinn Engineering](https://twinn.engineering).

### Can the AI change anything in Sage 100 Contractor?

Not on the demo. Access is read-only, so the server cannot post, edit, or delete records.

### Why did data I looked at yesterday change?

The demo company is rebuilt from scratch every night.

### Which AI clients are supported?

Any MCP client that supports remote servers over Streamable HTTP with OAuth. Setup steps for Claude and Cursor are in [Getting Started](getting-started.md).

### Where is the server source code?

The server is part of Twinn's commercially licensed platform and is not published. This repository holds documentation and configuration examples only.

### How do I report a problem?

Open an issue using the **Bug report** template.
